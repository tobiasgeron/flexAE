The `simulated_data.csv` file contains the simulated data used in Géron et al. (2026) to train flexAE. Please refer to Section 3.3 for details on how it was constructed. The file contains the following columns:

`g`: g-band apparent magnitude  
`g_err`: uncertainty in the g-band apparent magnitude  
`r`: r-band apparent magnitude  
`r_err`: uncertainty in the r-band apparent magnitude  
`i`: g-band apparent magnitude  
`i_err`: uncertainty in the i-band apparent magnitude  
`g-r`: g-r colour  
`g-r_err`: uncertainty in the g-r colour  
`g-i`: g-i colour  
`g-i_err`: uncertainty in the g-i colour  
`r-i`: g-r colour  
`r-i_err`: uncertainty in the r-i colour  
`g_abs`: g-band absolute magnitude  
`g_abs_err`: uncertainty in the g-band absolute magnitude  
`r_abs`: r-band absolute magnitude  
`r_abs_err`: uncertainty in the r-band absolute magnitude  
`i_abs`: i-band absolute magnitude  
`i_abs_err`: uncertainty in the i-band absolute magnitude  
`is_binary`: whether this simulated system is a binary (1) or a single star (0)
